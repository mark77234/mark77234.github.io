```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # -> ./out
```

## Deploy

`main` branch push → GitHub Actions (`.github/workflows/deploy.yml`) → GitHub Pages.
Repository Settings → Pages → Source: **GitHub Actions**.
